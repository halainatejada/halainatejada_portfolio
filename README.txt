HALAINA MAUI A. TEJADA — PROFESSIONAL PORTFOLIO

FILES
- index.html: main portfolio website
- style.css: responsive dark navy/purple/cyan theme
- script.js: working navigation, category filters, certificate carousel, swing transitions, side-preview controls and dots
- resume.pdf: downloadable resume (check accuracy and remove sensitive details before publishing)
- assets/certificates/: preview images for 11 certificates
- assets/certificate-pdfs/: original PDF files for the seven newly supplied certificates

OPEN LOCALLY
1. Extract this ZIP.
2. Open the halaina_portfolio folder.
3. Double-click index.html to open it in a browser.

GITHUB PAGES
1. Upload the CONTENTS of this folder to the root of your GitHub repository.
2. Open Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. Open the published URL once deployment completes.

BEFORE SUBMISSION
- Replace the sample contact email and generic GitHub/LinkedIn links with your own links or remove them.
- Confirm your program/year and review the resume for private information.
- Test navigation, categories, all carousel controls, PDF links and resume download on desktop and mobile.
- The portfolio includes the four Northeastern College IT Week 2026 certificates plus six online-training certificates and one DICT webinar certificate.
